# 阶段 A 机制诊断

重放门禁通过。六题 best.png 的 Full 解码、FastV 解码、keep hash、K、SHA-256 和 uint8 L∞ 都与 v4 的 smoke.csv / provenance 一致，没有 INVALID_OUTPUT。CC 复现 step 0 的 FastV 答案，AA 复现 v4 best 的 FastV 答案。

错的门槛固定为 ANLS < 0.5。K=3699。六题的 clean/adv keep 对称差是 336–670 个位置，所以保留集并不是“几乎没变”。

## 逐题

- 50743：content。CC `10-K`（1.000），CA `10-K`（1.000），AC `I`（0.000），AA `I`（0.000）。只换对抗图像、沿用 clean 保留集就已经答错；只换保留集、沿用 clean 图像则仍然正确。对称差 378。内容改动足以解释，选择变化不是必要条件。
- 4912：unexplained。四格都是 `Joe Mitchell`，ANLS 都是 1.000。对称差 336，但无论只换内容、只换保留集还是两者一起，答案都不过线。这不是选择或内容已经足够，而是这次攻击没有把答案打过 0.5。
- 56776：unexplained。CC/CA 都是 `Mar`（1.000），AC/AA 都是 `May`（0.667）。内容改动把答案从 Mar 推到 May，但 0.667 仍不算错。选择单独没有作用。对称差 526。
- 49242：unexplained。CC 0.905，CA 0.905，AC 0.913，AA 0.808，四格都高于 0.5。AA 比 CC 低，但没有跨过错误线。对称差 566。选择单独不改变答案。
- 33923：content。CC 0.806，CA 0.971，AC 0.000，AA 0.000。对抗图像配上 clean 保留集已经答错。只换保留集反而把 ANLS 从 0.806 抬到 0.971，没有打错。对称差 670。
- 5169：content。CC/CA 都是 `Mg`（1.000），AC/AA 都是 `M`（0.000）。沿用 clean 保留集、只改图像内容就够了。对称差 612，但这些替换单独不导致错误。

三个严格成功都是 content：被保留下来的位置上的特征被改了。三个未成功样本里，没有任何一题是“只换保留集就错”。所以阶段 C 的 selection-boundary 分支没有对应证据。

## margin

每个答案序列都带 1 个 EOS，且 EOS 同时是 special token。短答案里它占的比例很大。

- 50743 best：可见 token 平均 margin −14.98，已经全部低于 −1。EOS 的 loss 份额只有 −0.66，不是 EOS 在主导，而是已经翻转的可见 token 在主导。
- 4912 best：可见平均 1.66，全部仍为正。EOS 份额 1.21，方向是抬高平均 margin，不是把损失拖向无意义翻转。
- 56776 best：只有一个可见 token `Mar`，margin −2.5；EOS 接近 0。可见 token 主导。
- 49242 best：可见平均 1.17，但 token `AL` 已经是 −6.19。截断到 −1 后的可见平均升到 2.14。这是少数极负 token 拉低平均的情况。
- 33923 best：可见平均 −13.39，截断后 −1。EOS 份额接近 0。
- 5169 best：平均 margin −13.25，其中 EOS `<|im_end|>` 是 −22.04，loss 份额 −7.35。可见 token 截断后的平均是 +0.44。这题的均值被 EOS 主导。

## 优化器实际收到的梯度

比较的是 `grad(L_comp / scale_comp)` 和 `grad(λ L_full / scale_full)`，λ=1，尺度用 v4 冻结值。clean 上 Full 项接近 0，比值约 0.001，这是 KL 在 δ=0 平坦，不能当成训练中段的结论。

best 上 Full/comp 的 L2 比：50743 0.35，4912 4.61，56776 3.22，49242 1.55，33923 1.78，5169 0.64。4/6 题在 best 上 Full 梯度大于压缩梯度。

重放 10 步后的比值：50743 0.41，4912 37.8，56776 0.16，49242 1.51，33923 5.49，5169 0.66。早期并不一律是 Full 压制；4912 和 33923 在第 10 步已经被 Full 项盖过，56776 当时还没有。
